# Privacy

- This tool runs **entirely on your computer**. It makes no network requests.
- It never asks for your Instagram username, password, or session cookies.
- It only reads the JSON files from your own Instagram data export.
- Nothing is uploaded, logged, or sent anywhere.

Your export contains personal data. Keep it private, don't commit it to Git
(the included `.gitignore` helps), and delete it when you're done.
